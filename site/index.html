A whole robotics middleware stack in about 9,000 lines of Rust

Zero-copy transport, real time, control, deployment, tracing and recording, built on what Linux already ships. A learning project: each layer is the smallest thing that works, and every decision has a record.

5.6 µsround trip between two nodes on a machine, zero-copy
5 Mmessages a second between two nodes
21 µsfrom a joint's state to its command applied at 1 kHz; 1.3 µs spinning
6direct dependencies; the rest is the kernel

Try it

# a 1080p camera at 30 Hz, a detector, zero-copy; runs until stopped
git clone https://github.com/montmejat/keel && cd keel
cargo build
./target/debug/keel run examples/pipeline.yml

# in another terminal
./target/debug/keel top      # live view: ↑↓ select, f filter logs, g graph, s stop, q quit
./target/debug/keel trace    # where the time goes
./target/debug/keel stop

Then the examples: a control loop, a virtual CAN bus, two machines, a fleet, a flight recorder, the benchmarks.

keel is a learning project: how does a robotics middleware fit together when each layer is the smallest thing that works? Every design choice has a decision record.
